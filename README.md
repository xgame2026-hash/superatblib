# SuperARB LIQ2 1.7.0

## 链上清算与预测市场运营控制台

SuperARB LIQ2 1.7.0 是面向链上机会发现、清算运营与 Polymarket 周期套利的专业控制台。它将多链清算信号、风险状态、资金周期、市场数据、算力和运营通知统一到一个本地运行界面，帮助用户以更清晰、更可验证的方式管理链上策略。

LIQ2 不是收益承诺工具。所有收益、预测、候选与市场数据均受链上状态、流动性、滑点、网络费用、合约规则和市场波动影响；用户应独立判断并自行承担交易风险。

---

## 1. 1.7.0：更安全、更专业的架构升级

1.7.0 是一次面向实际运营的安全与体验升级。

### 自托管钱包架构

LIQ2 1.7.0 不接收任何钱包凭据，也不提供钱包凭据的存储、加密或解密功能。用户身份、服务套餐与客户端登录彼此分离：

- 授权码负责客户端访问验证；
- 执行钱包负责用户归属、链上资产读取及交易确认；
- 服务令牌与 RPC 配置用于套餐、额度及服务有效期校验；
- 所有资产操作均由用户钱包自行确认。

这种架构将资产签名权保留在用户钱包中，客户端和服务端都不成为钱包凭据保管方。

### 钱包原生确认

所有涉及钱包的动作统一采用 Reown 钱包连接能力，包括资金存入、资产兑换、卡槽购买、算力购买及资料所有权确认。用户可通过二维码、移动端或外部钱包完成连接，并在钱包内逐笔审阅交易内容。

### 可验证数据优先

页面重要数据优先使用链上合约状态、官方市场数据和已配置 RPC 返回结果；数据库只承担账户归属、通知和缓存加速等职责。对于卡槽、资金、奖励和交易结果，以链上记录为最终依据。

## 2. 清算套利：从机会发现到风险筛选

清算套利的本质，是在借贷协议出现高风险仓位时，识别可执行机会并在链上状态变化前完成复核。LIQ2 的清算专题将复杂的数据转化为面向运营的实时视图。

### 清算机会情报

系统持续归集支持协议与链上的候选仓位，并围绕以下维度进行筛选：

- 健康因子与风险等级；
- 债务规模、抵押物规模与资产集中度；
- 协议覆盖情况和链上可用性；
- 候选池、风险触发、可执行机会与高优先级队列；
- 执行成本、Gas、流动性和路由影响。

清算专题以图表、分布、漏斗和机会列表呈现这些数据。它强调“候选—复核—执行”的流程，而不是把任何候选地址视为保证收益。

### 风险控制

在执行前，策略仍需要重新核验最新链上状态。仓位可能已被其他参与者处理，价格与 Gas 也可能在区块间快速变化。LIQ2 将发现、监控和复核分层，让用户可以更快发现异常，也能在条件不满足时停止动作。

## 3. Polymarket 套利：资金周期与市场洞察

Polymarket 模块将预测市场的数据观察与周期资金管理整合在同一个界面中。

### 市场观察

- 聚合官方市场数据、流动性、成交量、盘口概率和价差；
- 提供市场筛选、检索与详情查看；
- 持续展示市场更新状态，减少依赖静态或模拟数据；
- 将市场信号与策略运营分离，便于独立判断。

### 周期本金管理

用户可在钱包确认后参与资金存入、周期管理与提取流程。控制台会分别展示：

- 当前在合约中登记的本金；
- 周期状态与锁定状态；
- 已发放的累计收益；
- 当前可执行或被周期规则限制的操作。

“我的收益”仅统计已经完成发放并被合约记账的累计收益，不将未结算金额、预估回报或市场浮盈提前计入。

### 算力与运营状态

算力模块读取链上套餐、供给、价格和暂停状态。若合约处于暂停或迁移状态，客户端会明确阻止交易发起，避免用户在不可执行状态下做出无效操作。

## 4. RPC 套餐与卡槽

LIQ2 将用户的钱包归属、RPC 套餐与卡槽订单统一管理。

| RPC 套餐 | 新用户卡槽上限 |
| --- | ---: |
| Build | 4 |
| Accelerate | 10 |
| Scale | 20 |
| Business | 100 |

每个新卡槽按 500 USDT 标准价格结算。购买流程由钱包确认，交易费用、网络费用和用户选择的滑点由购买者自行承担。历史订单保留真实链上记录；缓存仅用于提高页面加载速度。

## 5. 资产兑换

兑换模块支持 USDT 与抵押品 Token 的双向链上兑换。

- 输入任一方向金额后读取实时链上报价；
- 用户可选择预设滑点或自定义滑点；
- 页面会展示预计获得数量与最低接收保护；
- 钱包先确认必要授权，再确认实际兑换；
- 若市场价格变化超出滑点保护，交易会失败而不是以不可接受的价格执行。

这使兑换与卡槽购买、周期资金管理共享一致的钱包安全边界。

## 6. 本地启动

### 环境要求

- Node.js 20.19 或更高版本；
- npm；
- Git；
- 现代浏览器；
- 有效的服务访问配置、RPC 配置和 Reown Project ID。

### 安装

```bash
git clone https://github.com/xgame2026-hash/superatblib.git
cd superatblib/mt-dapp/liq2
cp .env.example .env
npm install
npm run dashboard
```

默认本地地址为：

```text
http://127.0.0.1:4311/
```

实际端口可通过以下命令查看：

```bash
npm run dashboard:url --silent
```

`.env` 仅用于本机运行，已被 Git 忽略，禁止提交。请以 `.env.example` 为参考填写所需配置，不要在截图、日志、Issue 或聊天中公开任何访问凭据。

## 8. 安全操作建议

- 使用独立执行钱包，不与长期资产钱包混用；
- 每次钱包确认前检查网络、资产、金额、授权对象和 Gas；
- 仅使用可信 RPC，并确认返回网络正确；
- 交易结果以钱包回执和链上浏览器记录为准；
- 不向客户端、网页、截图或日志提供任何钱包凭据；
- 不提交 `.env`、本地状态、访问凭据或个人资料缓存；
- 在异常授权、未知交易或资产异常时，立即停止操作并检查钱包授权。
